# TgBotReklama — бот-каталог сериалов с рекламной разблокировкой

Telegram-бот на Python: пользователь выбирает сериал, смотрит серию, а следующая
открывается после рекламного поста. Реклама бывает двух типов:

- **Платная реклама ТГК** — переход по кнопке обязателен, серия открывается только
  после нажатия кнопки со ссылкой и кнопки «Продолжить».
- **Затычка** — переход не обязателен, серия открывается сразу по кнопке
  «Продолжить».

Видео не хранится на сервере: бот сохраняет только `file_id` Telegram. Поэтому
общий объём сериалов может быть большим (десятки гигабайт), диск сервера не занят.

## Что уже готово

- Каталог сериалов и серий, бесплатные и платные серии.
- Постраничный список серий.
- Рекламный пост с фото/текстом и кнопкой-ссылкой.
- Проверка клика для рекламы ТГК.
- Автоматическая выдача серии после разблокировки.
- Постоянный доступ к открытым сериям.
- Админ-панель внутри бота: сериалы, серии, видео, реклама ТГК, статистика.
- Защита контента от пересылки (`protect_content`).
- SQLite, без Docker, Redis и внешних сервисов.
- Long polling: домен, HTTPS и вебхук не нужны.

## Стек

- Python 3.12+ (проверено на 3.14)
- aiogram 3.31
- SQLAlchemy 2 async + aiosqlite
- SQLite (`data/bot.db`)
- pydantic-settings

## Быстрый запуск на Windows

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой числовой ID у [@userinfobot](https://t.me/userinfobot).
3. Откройте `.env` и заполните:

   ```env
   BOT_TOKEN=123456789:AA...
   ADMIN_IDS=123456789
   ```

4. Дважды щёлкните `start.bat` (или запустите `run.py` в активированном venv).
5. В Telegram отправьте боту `/start`, затем `/admin`.

Подробная инструкция с пошаговой настройкой, работой 24/7, резервными копиями
и типовыми ошибками — в [RUN_TG.md](RUN_TG.md).

## Ручной запуск

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Linux/macOS:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python run.py
```

## Команды бота

| Команда | Назначение |
| --- | --- |
| `/start` | Главное меню и каталог |
| `/help` | Как работает разблокировка |
| `/admin` | Админ-панель (только для `ADMIN_IDS`) |

## Админ-панель

- **➕ Сериал** — название, описание, постер.
- **➕ Серия** — сериал, видео (или пропуск), название, сезон, номер,
  бесплатная/платная.
- **🎬 Прикрепить видео** — добавить или заменить видео у существующей серии.
- **📺 Сериалы** — включить/выключить сериал.
- **➕ Добавить рекламу** — реклама ТГК или затычка.
- **📣 Реклама ТГК** — включить/выключить рекламу.
- **📊 Статистика** — пользователи, показы, клики, CTR, открытия серий.
- **📖 Инструкция** — краткая памятка внутри бота.

Реклама ТГК имеет приоритет 100, затычка — 10. Пока активна хотя бы одна
реклама ТГК, бот показывает её; затычка используется, когда активной рекламы ТГК
нет. Если активной рекламы нет совсем, серия открывается без рекламы.

## Структура проекта

```text
app/
  main.py            запуск, polling, роутеры, логирование
  config.py          настройки из .env
  database.py        engine, сессии, init_db
  models.py          таблицы SQLAlchemy
  repo.py            запросы, реклама, клики, unlocks, статистика
  keyboards.py       inline-клавиатуры
  texts.py           тексты
  middlewares.py     сессия БД и пользователь
  services/
    ads.py           отправка рекламного поста
    delivery.py      отправка видео по file_id
    flow.py          логика открытия серии
  handlers/
    start.py         /start
    catalog.py       каталог и серии
    ads.py           клик и разблокировка
    admin.py         сериалы, серии, видео, статистика
    admin_campaigns.py реклама
    common.py        /help, заглушки, fallback
data/
  bot.db             база (создаётся автоматически)
  bot.log            лог (ротация 5 МБ × 3)
tests/               pytest
scripts/smoke_test.py интеграционный прогон без Telegram
deploy/              пример systemd-службы для VPS
```

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\smoke_test.py
```

`smoke_test.py` поднимает реальный диспетчер с фейковой Telegram-сессией, создаёт
сериал, две серии и рекламу, проходит путь пользователя и проверяет, что платная
серия не открывается без клика. База `data/smoke.db` удаляется после успеха.

## Ограничения

- Бот не может подтвердить фактический вход в чужой канал. «Клик» — это нажатие
  кнопки со ссылкой в рекламном посте. Если нужна проверка подписки, бота нужно
  сделать админом канала и использовать `getChatMember` (в этой версии не реализовано).
- Один файл через Bot API — до 2 ГБ. Общий объём 100 ГБ роли не играет, но серию
  больше 2 ГБ нужно разбить на части или делать HLS/Mini App.
- `file_id` привязан к токену бота. После смены токена видео нужно прикрепить заново.
- `protect_content` запрещает пересылку и сохранение, но не защищает от съёмки экрана.
- FSM хранится в памяти: незавершённый диалог админа сбрасывается при перезапуске.
