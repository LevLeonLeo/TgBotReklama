# Запуск TgBotReklama в Telegram

Пошаговая инструкция: от создания бота до рекламных кампаний и работы 24/7.
Всё, что нужно, уже лежит в папке проекта. Никаких доменов, HTTPS, Docker и
платных сервисов не требуется.

---

## 0. Что понадобится

- Windows-компьютер (или VPS с Linux) с интернетом.
- Python 3.12 или новее. В проекте уже есть виртуальное окружение `.venv`.
- Аккаунт Telegram.
- Второй Telegram-аккаунт для проверки (желательно).

Проверить Python:

```powershell
python --version
```

Если команда не найдена — установите Python с python.org и при установке
поставьте галочку **Add Python to PATH**.

## 1. Создайте бота у @BotFather

1. Откройте Telegram, найдите **@BotFather** (синяя галочка).
2. Отправьте `/newbot`.
3. Введите отображаемое имя, например `Мой сериальный бот`.
4. Введите username, он должен заканчиваться на `bot`, например
   `my_serial_2026_bot`.
5. BotFather пришлёт строку вида:

   ```text
   1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

   Это **BOT_TOKEN**. Никому его не показывайте: по нему можно управлять ботом.

Полезно сразу:

- `/setdescription` — описание бота до нажатия Start.
- `/setabouttext` — короткий текст в профиле.
- `/setuserpic` — аватар.
- `/setcommands` — не обязательно: бот сам установит команды при запуске.

Если токен случайно попал в чат или на скриншот — `/revoke` у BotFather и
вставьте новый токен в `.env`.

---

## 2. Узнайте свой числовой ID

1. Найдите **@userinfobot**.
2. Отправьте `/start`.
3. Он покажет `Id: 123456789`. Это ваш **ADMIN_IDS**.

Можно указать несколько админов через запятую:

```env
ADMIN_IDS=123456789,987654321
```

Важно: это именно числовой ID, а не `@username`.

---

## 3. Заполните .env

В папке `D:\OpenCode\TgBotReklama` откройте файл `.env` Блокнотом (или
Notepad++). Он выглядит так:

```env
BOT_TOKEN=
ADMIN_IDS=
SUPPORT_CONTACT=
AD_LABEL=Реклама
PAGE_SIZE=12
LOG_LEVEL=INFO
```

Заполните:

```env
BOT_TOKEN=1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
ADMIN_IDS=123456789
SUPPORT_CONTACT=@my_support
AD_LABEL=Реклама
PAGE_SIZE=12
LOG_LEVEL=INFO
```

- `SUPPORT_CONTACT` можно оставить пустым.
- `AD_LABEL` — надпись в начале рекламного поста.
- `PAGE_SIZE` — сколько серий показывать на одной странице (12 удобно).
- `LOG_LEVEL=DEBUG` нужен только для диагностики.
- Кавычки вокруг значений не ставьте.
- Файл сохраните в кодировке **UTF-8**.

Если файла `.env` нет, запустите `start.bat`: он создаст его из
`.env.example` и попросит заполнить. После заполнения запустите снова.

## 4. Запустите бота

Дважды щёлкните **`start.bat`**.

Что произойдёт:

1. Откроется консоль, включится UTF-8.
2. При необходимости создастся `.venv`.
3. Установятся зависимости (первый запуск может занять 1–3 минуты).
4. Появится строка вида:

   ```text
   ... Bot @my_serial_2026_bot started
   ```

5. Окно консоли должно оставаться открытым. Пока оно открыто — бот работает.

Если вместо запуска написано:

```text
BOT_TOKEN не задан...
```

закройте окно, заполните `.env`, запустите `start.bat` снова.

Если написано:

```text
Telegram отклонил BOT_TOKEN...
```

токен скопирован неверно или отозван. Проверьте `.env`.

Не запускайте два экземпляра бота одновременно: Telegram выдаст ошибку
`Conflict: terminated by other getUpdates request`. Закройте лишнее окно.

Проверка в Telegram:

1. Откройте своего бота по ссылке `https://t.me/ваш_username`.
2. Нажмите **Start** или отправьте `/start`.
3. Должно появиться приветствие. Если сериалов ещё нет — сообщение
   «Контент пока не добавлен» и подсказка `/admin`.

---

## 5. Добавьте сериал

Отправьте боту `/admin`. Появится админ-панель.

1. Нажмите **➕ Сериал**.
2. Введите название, например `Тестовый сериал`.
3. Отправьте описание текстом или нажмите **⏭ Пропустить**.
4. Отправьте постер фотографией или нажмите **⏭ Пропустить**.
5. Появится сообщение «Сериал добавлен» и снова админ-меню.

Постер лучше отправлять **фотографией**, не файлом. Если отправить файл,
бот попросит фото ещё раз.

---

## 6. Добавьте серии

1. В админке нажмите **➕ Серия**.
2. Выберите сериал кнопкой.
3. Отправьте видео **или** нажмите **⏭ Пропустить** (видео можно прикрепить позже).
4. Введите название серии, например `Пилот`.
5. Введите номер сезона: `1`.
6. Введите номер серии: `1`.
7. Нажмите **🎁 Бесплатная** или **🔒 Платная**.

Повторите для всех серий. Рекомендуемая схема:

- серия `1.1` — бесплатная;
- серия `1.2` — бесплатная (по желанию);
- серии `1.3` и дальше — платные (то есть с рекламой).

Серия с тем же сезоном и номером дважды не добавится: бот попросит ввести
другой номер.

### Как отправлять видео

Бот принимает:

- **видео** (обычное отправление видео);
- **файл** с MIME-типом `video/*` (например, `.mp4`, отправленный как файл).

Разница:

- **Видео** — Telegram сжимает и показывает в плеере, обычно удобнее для
  просмотра.
- **Файл** — сохраняется без сжатия, но пользователь скачивает его как документ.

Если серия уже создана без видео:

1. **🎬 Прикрепить видео**.
2. Выберите сериал.
3. Выберите серию.
4. Отправьте видео или файл.
5. Появится «Видео прикреплено».

Можно заменить видео: повторите те же шаги, старое заменится.

### Ограничение 2 ГБ

Один файл через Telegram Bot API — **до 2 ГБ**. Общий объём может быть хоть
100 ГБ: бот хранит только `file_id`, сами видео лежат на серверах Telegram.

Если одна серия больше 2 ГБ:

- разбейте её на части и добавьте как отдельные серии/эпизоды;
- либо позже сделайте HLS-плеер в Mini App (это отдельная разработка).

Загружать 100 ГБ на диск сервера не нужно.

## 7. Создайте рекламную кампанию

В админке нажмите **➕ Кампания**. Выберите тип.

### Вариант A. Платная реклама ТГК

Клик по ссылке обязателен. Серия откроется только после:

1. нажатия кнопки со ссылкой в рекламном посте;
2. нажатия «✅ Продолжить».

Шаги:

1. **📣 Платная реклама ТГК**.
2. Название кампании для админки, например `Канал X, октябрь`.
3. Текст рекламного поста. Пример:

   ```text
   Смотрите новый канал о сериалах и кино.
   Подборки, обзоры и ранние анонсы.
   ```

   Текст отправляется как обычный текст: HTML-теги не работают, эмодзи можно.
4. Текст кнопки или **⏭ Пропустить** (по умолчанию «Перейти в канал»).
5. Ссылка. Подойдёт:

   ```text
   https://t.me/channel_name
   t.me/channel_name
   @channel_name
   https://t.me/+AbCdEfGhIjK
   https://example.com/page
   ```

6. Фото для поста или **⏭ Пропустить**.
7. Готово. Кампания активна и имеет приоритет 100.

### Вариант B. Затычка-рефералка

Клик не обязателен: пользователь сразу нажимает «✅ Продолжить» и получает серию.
Рекламный пост всё равно показывается.

Шаги те же, но выберите **🔁 Затычка-рефералка**. Приоритет — 10.

### Как бот выбирает кампанию

- Пока есть **активная платная** кампания, показывается она (приоритет 100).
- Если платных активных нет — показывается **затычка** (приоритет 10).
- Если активных кампаний нет совсем, серия открывается **без рекламы**.
- Если активных платных несколько — выбирается случайная среди них.
- Если активных затычек несколько — случайная среди них.

Чтобы временно переключиться на затычку, откройте **📣 Кампании**, нажмите на
платную кампанию (она станет 🔴), затем включите затычку. Вернуть обратно —
нажать ещё раз.

Кампании нельзя редактировать: если ошиблись в тексте или ссылке, создайте новую
кампанию, а старую отключите. Сериалы и серии тоже не редактируются (кроме
замены видео); чтобы исправить название, создайте заново и отключите старое.

### Что именно проверяется

Бот фиксирует **нажатие кнопки со ссылкой**. Telegram не сообщает ботам, вступил
ли пользователь в чужой канал и дочитал ли пост. Поэтому «подтверждённый переход»
— это клик по кнопке, после которого бот сразу открывает ссылку (и дублирует её
кнопкой в посте на случай, если клиент не открыл URL автоматически).

Если рекламодателю нужна именно проверка подписки на канал, бота нужно добавить
админом этого канала и проверять `getChatMember`. В текущей версии этого нет.

## 8. Проверьте с второго аккаунта

1. Откройте бота вторым аккаунтом, отправьте `/start`.
2. **📺 Каталог** → сериал.
3. Нажмите бесплатную серию — видео должно прийти сразу.
4. Нажмите платную серию:
   - появится рекламный пост;
   - нажмите кнопку со ссылкой;
   - вернитесь в бота;
   - нажмите **✅ Продолжить**;
   - должна прийти серия.
5. Проверьте, что в списке серий она отмечена ✅ и открывается повторно без рекламы.
6. Откройте `/admin` → **📊 Статистика**: должны увеличиться показы, клики и
   открытия.

Проверка затычки:

1. Отключите платную кампанию.
2. Создайте/включите затычку.
3. Новым аккаунтом откройте платную серию.
4. Нажмите **✅ Продолжить** без перехода по ссылке — серия должна открыться.

Если что-то не так, смотрите `data/bot.log` и раздел «Ошибки» ниже.

## 9. Работа 24/7

### Вариант A. Windows-компьютер

Подойдёт, если компьютер включён постоянно.

1. Не закрывайте окно `start.bat`.
2. Отключите спящий режим: Параметры → Система → Питание → Спящий режим → «Никогда».
3. Чтобы бот запускался сам после входа в Windows:
   - нажмите `Win + R`, введите `taskschd.msc`, Enter;
   - **Создать задачу** (не «простую»);
   - вкладка **Общие**: имя `TgBotReklama`, «Выполнять только при входе
     пользователя»;
   - вкладка **Триггеры** → **Создать** → «При входе в систему»;
   - вкладка **Действия** → **Создать** → «Запуск программы»;
     - программа: `D:\OpenCode\TgBotReklama\start.bat`
     - рабочая папка: `D:\OpenCode\TgBotReklama`
   - вкладка **Условия**: снимите «Запускать только при питании от сети»;
   - вкладка **Параметры**: поставьте «Перезапускать при сбое» каждые 1 мин,
     если есть такой пункт;
   - сохраните задачу.

После перезагрузки бот поднимется сам. Проверьте, что в Telegram он отвечает.

### Вариант B. VPS с Linux (рекомендуется для стабильности)

Минимальный VPS: 1 CPU, 1 ГБ RAM, 10 ГБ диска. Видео на VPS не хранятся.

Можно установить вручную по шагам ниже или автоматически:

```bash
# проект уже загружен в /tmp/TgBotReklama
cd /tmp/TgBotReklama
sudo bash deploy/install_vps.sh
sudo nano /opt/TgBotReklama/.env      # BOT_TOKEN и ADMIN_IDS
sudo systemctl enable --now tgbot
```

Скрипт создаст пользователя `tgbot`, окружение, службу systemd и ежедневный
бэкап. Повторный запуск обновляет код, сохраняя `data/` и `.env`.

Ручная установка:

Кратко:

```bash
sudo apt update
sudo apt install -y python3 python3-venv

# скопируйте папку проекта, например через scp/rsync,
# в /opt/TgBotReklama
cd /opt/TgBotReklama

sudo useradd -r -s /usr/sbin/nologin tgbot 2>/dev/null || true
sudo chown -R tgbot:tgbot /opt/TgBotReklama

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

nano .env       # BOT_TOKEN и ADMIN_IDS
.venv/bin/python run.py   # проверка, затем Ctrl+C
sudo chown -R tgbot:tgbot /opt/TgBotReklama
```

Создайте службу `/etc/systemd/system/tgbot.service` (готовый пример лежит в
`deploy/tgbot.service.example`):

```ini
[Unit]
Description=TgBotReklama
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=tgbot
WorkingDirectory=/opt/TgBotReklama
ExecStart=/opt/TgBotReklama/.venv/bin/python /opt/TgBotReklama/run.py
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

Замените `User=tgbot` на своего пользователя (или создайте его). Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tgbot
sudo systemctl status tgbot
journalctl -u tgbot -f
```

Обновление кода:

```bash
sudo systemctl stop tgbot
# заменить файлы
.venv/bin/pip install -r requirements.txt
sudo systemctl start tgbot
```

## 10. Резервные копии

В базе хранятся пользователи, сериалы, серии, кампании, клики и открытия.
Видео в базе нет — только `file_id`.

Правильная копия:

1. Остановите бота (Ctrl+C или `sudo systemctl stop tgbot`).
2. Скопируйте папку `data` целиком (там `bot.db`, а при работе ещё `-wal`/`-shm`).
3. Скопируйте `.env` отдельно.
4. Запустите бота снова.

Храните копии в другом месте, например `D:\Backups\TgBotReklama\2026-10-24`.

Восстановление:

1. Остановите бота.
2. Верните папку `data` и `.env`.
3. Запустите.

Важно: `file_id` привязаны к токену бота. Если токен сменили, видео нужно
прикрепить заново, даже если база восстановлена.

## 11. Ошибки и решения

### Бот не запускается: `BOT_TOKEN не задан`

Файл `.env` пустой или лежит не в папке проекта. Заполните `BOT_TOKEN` и
`ADMIN_IDS`, сохраните UTF-8, запустите снова.

### `Telegram отклонил BOT_TOKEN`

Опечатка, лишние пробелы или токен отозван. Скопируйте токен у BotFather заново
(кнопка API Token), вставьте без кавычек.

### `Conflict: terminated by other getUpdates request`

Запущены два бота с одним токеном. Закройте лишние окна/службы. На VPS:

```bash
sudo systemctl stop tgbot
ps aux | grep run.py
```

### `ModuleNotFoundError: No module named 'aiogram'`

Запуск не через venv. Используйте `start.bat` или активируйте окружение:

```powershell
.\.venv\Scripts\activate
python run.py
```

### `No module named 'greenlet'`

Выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### Админка не открывается

- `ADMIN_IDS` — числовой ID, не username.
- После изменения `.env` бота нужно перезапустить.
- Проверьте, что ID принадлежит тому аккаунту, с которого пишете.

### «Серия недоступна» / «Сериал временно недоступен»

Сериал или серия выключены либо удалены. В `/admin` → **📺 Сериалы** включите
сериал. Если серия была удалена из базы, добавьте её заново.

### «Видео для этой серии ещё не загружено»

Прикрепите видео: `/admin` → **🎬 Прикрепить видео** → сериал → серия → видео.

### «Не удалось отправить видео»

- Прикрепите видео заново.
- Проверьте, не менялся ли `BOT_TOKEN`.
- Посмотрите `data/bot.log`.
- Убедитесь, что файл не больше 2 ГБ.

### Реклама не появляется

- Серия отмечена бесплатной.
- Нет активных кампаний (тогда серия открывается без рекламы).
- Платная кампания отключена, а затычка не включена.

### Кнопка со ссылкой не открывает URL

Бот после клика заменяет кнопку на прямую ссылку `... ↗`. Нажмите её. Некоторые
клиенты Telegram не поддерживают автоматическое открытие URL из callback.

### В консоли кракозябры

Запускайте через `start.bat` (там `chcp 65001`). Лог-файл всегда UTF-8.
Если запускаете вручную:

```powershell
chcp 65001
$env:PYTHONUTF8=1
python run.py
```

### Бот молчит после перезагрузки Windows

Проверьте задачу в Планировщике, отключён ли сон, запущен ли `start.bat`.
Откройте `data/bot.log` — там будет причина.

### Антивирус/Defender ругается на Python

Разрешите Python и папку проекта. Это обычный Python-скрипт, но эвристика
иногда реагирует на автозапуск.
